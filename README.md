# 🌍 Country Data Web Scraper

A lightweight and efficient Python web scraper built to extract comprehensive country metrics from public data portals.

## 🛠️ Features
- **Clean HTML Parsing:** Built using `BeautifulSoup4` and `Requests`.
- **Anti-Bot Standard:** Implements custom headers to mimic organic browser requests.
- **Structured Output:** Automatically sanitizes and outputs data into a normalized `countries_data.csv` file.
